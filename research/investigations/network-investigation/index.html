Go to the bibliography

Network investigation uses observations of communications and relationships between systems to answer a defined question. The interpretation of an address, connection or traffic pattern depends on the collection point, time period and supporting context.

Scope of this collection

This collection contains papers assigned to the Network Investigation application. Their research categories can differ, because an investigative use is separate from a subject classification. The bibliography is a research starting point rather than a set of current network indicators.

Using this research

Compare what each method observes, how it establishes ground truth and what information is absent. Shared infrastructure and changes over time can complicate the meaning of an address-level association. Use the original study to assess which conclusions follow from the data it actually collected.

References reproduce the metadata held by ALEX. Missing author, year or source details are identified in the listing. Publication years are shown as recorded; collection and retrieval dates are not substituted. Follow the original source to verify a citation.
