# Isolated credentialed registry enrichment

Use tools/content_review/registry_worker.py and .github/workflows/content_review_registry.yml only for one consequential exact-DOI OpenAlex lookup per worker run, after independent material/access/metadata/duplicate checks and existing text hard gates. The supported repository OPENALEX_API_KEY secret is mapped to the existing environment/parameter names; an unavailable key returns a hold with zero requests, never an anonymous fallback. No key values, request URLs with auth params or error bodies are logged.

Prepare an immutable config/content_review_registry_requests/<request_id>.json with schema_version1, current candidate/content/DOI, exact manifest byte SHA256, first-four-gate evidence digest, current lease owner and a six-hour maximum expiry. request_id is the canonical JSON SHA256 excluding request_id, using the same digest contract as the worker. Current supported case: an undecided verified weekly research paper whose only consequential quality issue is a provisional below-threshold score with unknown citations; core/relevance hard gates must pass. Other cases remain held until explicitly supported.

The workflow reads the exact push snapshot, requires a current matching unexpired lease and elapsed provider cooldown, and uses contents:read with checkout credentials disabled. It tests before exposing the secret, issues at most one20-second GET (no redirects/retries/batching), and emits a credential-free result artifact/log line. HTTP429/5xx/timeouts end provider work; persist full Retry-After across runs. An elapsed historical cooldown does not establish recovery. No source manifest, scoring, corpus, import, merge or deployment is mutated by the runner.

Consume by independently fetching the Actions run and job logs: verify review branch, push event, exact .github/workflows/content_review_registry.yml path, request commit/run/attempt and terminal conclusion. Match every artifact provenance field, request/candidate/content identity and exact DOI. Match title/authors against the already verified work before attaching cited_by_count; preserve publication/issue-year distinctions. Keep citation counts from different providers separate, never substitute reference counts or invent zero. Recompute the existing scorer only after a valid count is bound to the current record. A registry success is neither schema completion nor manual admission.

Save an immutable config/content_review_registry_receipts/<request_id>.json with run proof, result and actual request count; checkpoint any count/gate updates separately. Reuse completed evidence and do not reissue the same request to poll it.
