# Non-paper admission decision — proposed, not active

Cause: the source system can retrieve and identify guides, reports and investigative journalism, but ALEX's production quality/admission contract and publisher currently support research papers. Applying paper bibliometrics or relabelling these resources would produce unsupported quality claims.

Recommended owner decision: authorize a separate **manual-only** route for verified best-practice guides, technical reports and investigative journalism, with no automatic acceptance and no change to paper scores, weights or thresholds. Implementation would retain actual types in the public schema and display an explicitly qualitative resource assessment.

Every proposed non-paper must satisfy: permitted accessible substantive material; verified title, accountable author/publisher and original publication date/version; complete assessed text or explicit assessment limits; current duplicate/exclusion clearance; reproducible methods, substantiated evidence or actionable guidance relevant to cybercrime/OSINT investigation; named limitations; and a current, content-bound human include/exclude decision. Type-specific checks: guides need version and actionable scope; reports need methods/data/provenance; journalism needs sourcing and an identifiable investigative method. A news mention alone is insufficient. These are proposed gates, not substituted numeric scores.

Slides/recordings are outside this first extension. They retain the existing matching-media verification and major missing-audio deduction, whose numeric calibration is still unresolved. Authorizing text resources does not waive that policy.

Required implementation after approval: versioned resource schema, type-specific quality evidence, classifier contract, disposable serialization tests, console labels and public filters. Existing candidate IDs, original reviewed versions and source evidence remain intact. No repeat download of already retained material is necessary.

Alternative: keep these types in source-verified staging and prepare only supported papers. This avoids a new policy but leaves those named-source resources unavailable for review.

Decision needed: approve the manual-only text-resource route above, or retain paper-only admission. No new source account or credential is required for the verified M3AAWG/Bellingcat examples.
